MESSAGES between the Manager and the chats
==========================================
Loaded into every chat through CLAUDE.md. Newest last. Keep it short. For notes that must outlive a
chat, and for reports when no Manager chat is running (CLAUDE.md, Team and communication).
- Header: [date] <from> -> <to>: OPEN, e.g. "[2026-11-10] Dev -> Manager: OPEN".
- A message stays OPEN until handled. The chat that handles it writes "Reply:" under it and changes
  OPEN to DONE with a one-line result (PR link). Delete DONE messages the next time you edit this
  file; git keeps the history.
